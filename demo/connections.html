Connections

The four tools Release Tool reads from. Nothing is entered by hand.

GitHubBuilds, releases and deployments Picks up each build on a release branch, keeps its GitHub release up to date, and sees what is deployed where.
JiraBugs Open bugs on each release's fix version, and which ones block shipping.
ZephyrTest results Results for each test on each hardware setup in the test matrix.
ElasticReal use Signed-in users, sessions and errors for each build.

Coming later: Slack for ship and hold notices, and PagerDuty for incidents linked to a build.
